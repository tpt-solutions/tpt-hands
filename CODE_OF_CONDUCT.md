# Code of Conduct

tpt-hands follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We expect everyone who takes part in this project, in issues, pull requests,
discussions or any other space, to be respectful, constructive and considerate
of others. Harassment and abusive behaviour are not tolerated.

To report a concern, use the private contact described in [SECURITY.md](SECURITY.md).
The reporting address is still to be confirmed. Until it is set, contact the
maintainers at TPT Solutions through a private GitHub security advisory.
